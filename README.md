# 🌾 गन्ना हाट (GannaHaat)
> ग्रामीण भारत के गन्ना किसानों और चीनी मिलों/गुड़ व्यापारियों के लिए संपूर्ण द्विभाषी (हिंदी / English) डिजिटल नीलामी मंच।

---

### 🚀 मुख्य विशेषताएं (Key Features)

- **द्विभाषी अनुवाद (Bilingual i18n):** नेविगेशन बार में instant `[हिंदी | English]` टॉगल।
- **🌾 किसान मॉड्यूल (Farmer Module):**
  - मोबाइल नंबर + 4-अंकीय पिन से सुरक्षित प्रवेश।
  - गन्ने की बिक्री प्रविष्टि (किस्म उदा. Co 0238, Co 0118, Co 15023, मात्रा क्विंटल में, कटाई स्थिति, न्यूनतम भाव, खेत का स्थान)।
  - आई हुई बोलियों की लाइव सूची और **बोली स्वीकार (Accept)** या **अस्वीकार (Reject)** करने की सुविधा।
  - सौदा पक्का होने पर खरीदार/मिल का संपर्क व पता अनलॉक।
- **🏢 खरीदार मॉड्यूल (Buyer / Mill Module):**
  - गन्ना मंडी (Marketplace) में लाइव फसलों की खोज व ज़िला/किस्म अनुसार फ़िल्टर।
  - आधार भाव से ऊपर प्रति क्विंटल प्रतिस्पर्धी बोली लगाना।
  - "मेरी बोलियाँ" डैशबोर्ड में स्थिति ट्रैकिंग (प्रतीक्षारत / स्वीकृत / अस्वीकृत)।
  - सौदा स्वीकृत होने पर किसान का फोन नंबर व खेत का स्थान अनलॉक।
- **🛡️ व्यवस्थापक मॉड्यूल (Admin Panel):**
  - KPI मेट्रिक्स: कुल किसान, कुल खरीदार, लाइव लिस्टिंग्स, लंबित सत्यापन, कुल बोलियाँ।
  - नई लिस्टिंग्स का 1-क्लिक अनुमोदन (Approve) या कारण सहित अस्वीकृति (Reject)।
  - उपयोगकर्ता प्रबंधन (किसान व खरीदार खातों को सक्रिय/निलंबित करना)।
  - पूरे राज्य में चल रही बोलियों का लाइव ऑडिट।

### 🛠️ तकनीकी स्टैक (Tech Stack)

- **फ़्रेमवर्क:** Next.js (App Router, Turbopack, TypeScript)
- **स्टाइलिंग:** Tailwind CSS (गन्ना हरा व गुड़ गोल्डन रंग, बड़े टच-टारगेट)
- **डेटाबेस:** MySQL 8.0
- **ORM:** Prisma Client & Migrations
- **प्रमाणीकरण:** Auth.js (NextAuth) — 10-अंकीय मोबाइल + 4-अंकीय पिन / मॉक OTP
- **फॉर्म्स व वैलिडेशन:** React Hook Form + Zod Schemas

### 💻 स्थानीय निष्पादन निर्देश (Local Setup & Run)

```bash
# 1. रिपॉजिटरी में जाएं
cd f:/GannaHaat

# 2. निर्भरताएं इंस्टॉल करें
npm install --legacy-peer-deps

# 3. डेटाबेस सिंक करें (MySQL)
npx prisma db push

# 4. डेमो डेटा सीड करें
npx tsx prisma/seed.ts

# 5. डेवलपमेंट सर्वर शुरू करें
npm run dev
```

ब्राउज़र में खोलें: `http://localhost:3000`
